# `labs`

Colab lab notebooks referenced from [shuuchuu/slides](https://github.com/shuuchuu/slides)
training decks, mirrored here from Google Drive/GitHub so they have a stable,
version-controlled home.

Notebooks are organized under `notebooks/` in the same layout as the shared
training sections they belong to, e.g. `notebooks/python/basics/variables/tp.ipynb`
mirrors the `python/basics/variables` section.

Open any notebook directly in Colab by swapping the GitHub blob URL for:

```
https://colab.research.google.com/github/shuuchuu/labs/blob/main/notebooks/<path>.ipynb
```
